# BLACK & BREW — Coffee House Landing Page

A luxury, cinematic coffee house landing page built with **React**, **Vite**, **Framer Motion**, **Lucide React**, and **Lenis** smooth scrolling.

## Features
- **Black & Golden Yellow Design Identity** (`#080808`, `#141414`, `#FFC928`)
- **Sticky Glassmorphism Navbar** with dynamic active section pill and interactive Order Bag counter
- **Hero Section** with staggered heading reveal, scroll parallax, floating coffee bean particles, CSS rising steam, and custom studio photography
- **Features Bar**, **Asymmetrical About Section** (`Since 2018` badge & cursive *"Sip Smile Repeat"*), **4-Card Signature Menu**, **Interactive Testimonial Carousel**, **Golden CTA Banner**, and **Footer**
- **Interactive Modals**: Full Menu & Pickup Order Bag, Masonry Coffee Gallery, Brand Video Film Reel, Our Story Timeline, and Location/Reservation Form

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
